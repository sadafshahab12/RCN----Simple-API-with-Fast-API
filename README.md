## FastAPI

- FastAPI is a modern, high-performance web framework for building APIs with Python 3.7+ based on standard Python type hints.

### Why it's called Fast:

- Speed: It's one of the fastest Python frameworks, only slightly slower than Node.js and Go in benchmarks.
- Development speed: Thanks to automatic docs, data validation, and type hinting, you can build and test APIs way faster than with traditional frameworks.

#### Example:

- Imagine you're building a lemonade stand, and you want people to be able to ask for lemonade in different ways—like:

- “Can I have one cup?”
- “What flavors do you have?”
- “How much does it cost?”

- Now, instead of talking to each person, you build a robot helper who understands these questions and gives the right answers.

**FastAPI is like a tool that helps you build that robot helper using Python**
